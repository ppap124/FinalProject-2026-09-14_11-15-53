# 동생 시스템 (상세)

> 본 문서는 [기획.md](기획.md) 8장의 확장. 최종 갱신 2026-09-14

동생 강**정우** (가칭) · 1972년생 · 형과 10살 차
0막(1980) 8세 → 3막(1990) 18세 → 4막(1991~) 19세~

## 1. 두 개의 축이 결말을 정한다

|  | **형을 모름** | **형을 앎** |
|---|---|---|
| **공부시켰다** | 평범한 성공 — 회사원, 교사 | **법조인 → 검사** |
| **안 시켰다** | 평범하게 산다 — 공장, 가게 | **같은 세계로 들어온다** |

- **학업** : 형이 매턴 학비를 댔는가. 돈과 턴이 든다.
- **앎** : 악명에 비례해 매턴 자동 증가. 동생은 소문을 듣는다.

### 학비가 빚과 싸운다
같은 돈을 빚에 넣을 것인가 학원비로 쓸 것인가.
학비를 대려고 무리하면 → 악명↑ → **앎↑** → 노리던 칸(평범한 성공)에서
옆 칸(법조인)으로 밀려난다. 좋은 형이 되려는 노력이 나를 잡을 사람을 만든다.

## 2. 존경 ↔ 경멸 = 제3의 값

결말 칸은 학업×앎이 정하고, **존경/경멸은 그 안에서 태도를 정한다.**
단순한 톤이 아니라 **3막의 생사 판정에 직접 쓰인다.**

- 존경↑ : 돈을 갖다줌 · 약속을 지킴 · 집에 들어옴
- 경멸↑ : 약속을 어김 · 집에 안 들어옴(업소/조직 턴) · 폭력을 보임

## 3. 3막(1990) — 동생은 아직 18세다

법조인이 아니다. 그러므로 3막의 도움은 **법조인이라서가 아니라 동생이라서** 주는 것.

형사가 동생을 잡고 압박한다. "형 어디 있어?"

| 동생 상태 | 3막 |
|---|---|
| 존경 높음 | 입을 다문다 · 은신처를 대준다 · 알리바이 |
| 경멸 높음 | 분다. 혹은 그냥 모른 척한다 |

→ 존경이 낮으면 3막 생존 확률이 직접 깎인다.

### 명의 딜레마 (3막의 핵심 선택)
3막은 버는 막이 아니라 **지키는 막**. 돈을 숨기려면 명의가 필요하다.
가장 안전한 명의는 동생이다.

- **쓴다** → 재산 보존 → 4막 정복 가능 → **동생이 공범이 된다. 법조인 루트 소멸**
- **안 쓴다** → 재산 상당수 압류 → 4막에 정복할 힘이 없다

→ **진엔딩(정복→몰락)으로 가려면 동생을 팔아야 한다.**
주제가 시스템으로 증명되는 지점.

### 동생이 이미 그 세계에 있다면 — 체포 이벤트
범죄와의 전쟁은 싹쓸이다. 급이 낮고 어린 놈부터 잡힌다. **동생이 먼저 잡힌다.**

- **빼낸다** → 돈·인맥·형사 카드를 태운다 → 내 생존 확률 급감
- **안 빼낸다** → 동생이 감옥에 간다. 나오면 완전히 그 세계 사람이 된다

## 4. 4막 이후 — 법조인 루트가 작동한다

4막(1991~)에 동생은 법대생 / 고시생 / 연수원생.

| 존경/경멸 | 4막 |
|---|---|
| 존경 | 정보를 흘려준다. 수사 방향을 알려준다 |
| 경멸 | 연락을 끊는다. 최악의 경우 자료를 넘긴다 |

**검사가 되는 것은 엔딩 에필로그에서 처리.** "몇 년 뒤" 한 줄로 시간 문제 해결.

### 0막의 검사와 연결
0막에 한 번 스친 부잣집 아이 = 3막의 검사.
동생이 법조인이 되면 **그 사람 밑에서 시작한다.**
내가 평생 못 닿은 세계에 내 손으로 동생을 밀어 넣었고, 그 세계가 나를 잡는다.

## 5. 4막 중 결정적 한 줄

> 나 법대 갈 거야.

플레이어가 얼어붙는 순간. 좋은 일인데 좋은 일이 아니다.

## 6. 진엔딩(정복→몰락)에 붙였을 때

| 동생 | 마지막 화면 |
|---|---|
| 같은 세계 | 내가 무너진 자리를 동생이 물려받는다. **대가 이어진다** |
| 법조인 | 내가 무너진 이유가 동생이 가는 길이다. **대가 끊긴다** |
| 평범 | 끝까지 모른다. 뉴스로 형 소식을 본다 |

### 대사 톤 (칸 4개 × 존경/경멸 = 8개)
법조인 · 존경 → "형이 옳았다고 생각한 적은 없어. 근데 왜 그랬는지는 알아."
법조인 · 경멸 → 아무 말도 하지 않는다. 서류만 넘긴다.
